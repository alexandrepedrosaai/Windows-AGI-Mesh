# VA Q-learning Neural Quantum Polymorphism

This executable is a deterministic research scaffold for a variational-ansatz (VA) Q-learning loop. It demonstrates polymorphic quantum-state interfaces with computational and variational state families, an epsilon-greedy Q-learning update, and a small neural-style score aggregation.

The implementation is intentionally a local, testable .NET component. It does not claim to simulate a fault-tolerant quantum computer, provide quantum advantage, or encrypt release artifacts. Build it with:

```bash
dotnet run --project quantum/VAQLearningNeural/VAQLearningNeural.csproj
```
