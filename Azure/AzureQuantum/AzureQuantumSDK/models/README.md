# Model Weights

This directory contains the model registry and weight manifests.

## Files

- registry.json: Model version registry (auto-generated)
- weights/example.manifest.json: Example weight shard manifest

## Quantization

- BF16: ~10 GB total
- INT4 (hybrid): ~2.5 GB total
- FP8 (MAIA-300): ~1.25 GB total
