# Example mesh workflow

1. The `Nemotron` dataset circuit publishes a provenance-checked, versioned evaluation manifest.
2. `EdgeAIApp` loads a compatible signed model on a Windows PC and performs inference locally.
3. `AGIMeshWeb` evaluates the model in an isolated run using a held-out benchmark split.
4. `DeepSpace` stores encrypted results and verifies recovery under a declared fault profile.
5. `MagneticMajorana` can analyze simulator-only persistence experiments, while `XboxQuantumXR` can visualize approved, sanitized summaries.

Each handoff uses authenticated, versioned contracts. Local data stays on-device unless a user explicitly authorizes a documented transfer. Results retain module, data, model, and configuration versions so an evaluation can be reproduced.
